# CoinCollection — catalogo

Catalogo delle monete in euro (conio normale e 2 € commemorativi) letto dall'app CoinCollection
per aggiornarsi senza un nuovo rilascio.

- `manifest.json`: versione del catalogo, versione minima dell'app e SHA-256 di `catalog.json`.
- `catalog.json`: paesi e monete. Gli ID sono stabili e non vengono mai rimossi.

I file sono generati e non vanno modificati a mano.
